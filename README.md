# FreeNet Malawi

An Android learning and research project exploring affordable, lawful internet connectivity options in Malawi, including Airtel Malawi, TNM, Wi-Fi, and community connectivity.

## Important notice

This app is an educational prototype. It does **not** provide free mobile data, bypass carrier billing, or connect to a VPN server. Mobile network data charges still apply according to the user's plan.

Any future network or VPN features must use services and servers that the project owner is authorized to access.

## Current prototype

- Select a connection type for learning: Wi-Fi, Airtel Malawi, or TNM.
- Read a clear explanation of what the selection means.
- No background networking, tunnelling, or data-billing circumvention.

## Build

The Android app is built with Kotlin and the Android Gradle Plugin. GitHub Actions is configured to build a debug APK.

## Project direction

1. Establish a reproducible Android build.
2. Learn Android app structure and networking concepts.
3. Research lawful options such as sponsored data, community Wi-Fi, and authorized VPN access.
4. Add network features only when their service, permissions, and costs are understood.
